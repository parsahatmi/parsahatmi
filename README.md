## 🛍️ Featured Project

### Vanilla Shop

A full-featured e-commerce platform built with **Django, Django REST Framework, and PostgreSQL**.

**Key features:**

* 🔐 OTP-based authentication
* 🍪 JWT authentication with HTTP-only cookies
* 🛒 Shopping cart
* ❤️ Wishlist
* 🏷️ Discount codes
* 📦 Product & variant management
* 🚚 Shipping calculation
* 📋 Order management
* 🔒 Stock reservation
* 💳 Online payment integration
* ♻️ Return & refund management
* 🛡️ Idempotent order creation
* 🔁 Duplicate payment/request protection
* 📡 REST APIs
* 📱 Responsive frontend
* 🚀 Production deployment
